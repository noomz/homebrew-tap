# noomz/tap

Homebrew formulae for noomz's tools.

```sh
brew install noomz/tap/sketchybar-theme-manager
```

| Formula | Project |
|---|---|
| `sketchybar-theme-manager` | [Theme manager for SketchyBar](https://github.com/noomz/sketchybar-theme-manager) |

The formula is copied from that project's `Formula/` directory on each release.
